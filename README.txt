YANGIN DENETİM PRO - TELEFONDA UYGULAMA GİBİ ÇALIŞAN PWA

Bu klasör bir PWA'dır.
1) Dosyaları bir web sunucusuna yükleyin (ör. GitHub Pages).
2) Telefon Safari/Chrome'dan siteyi açın.
3) iPhone'da Paylaş > Ana Ekrana Ekle seçin.
4) Uygulama gibi açılır.

Özellikler:
- 6 yapı türüne göre checklist
- Uygun/Uygunsuz/Kısmen Uygun
- Risk seviyesi
- Tespit ve önerilen tedbir
- Fotoğraf alanı
- İşletme kayıtları ve geçmiş denetimler
- Tekrar denetim tarihi
- JSON yedekleme/geri yükleme
- Yazdır/PDF
- Çevrimdışı önbellek (ilk web yüklemesinden sonra)
